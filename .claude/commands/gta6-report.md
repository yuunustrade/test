description: GTA 6 page analytics — log metrics, daily report, or weekly review
argument-hint: "daily | weekly | metrics <paste numbers>"
---

Run the **gta6-analyst** subagent on the `gta6-studio/` workspace with this request: $ARGUMENTS

- `daily` → write today's daily report (Europe/Rome date) and list posts awaiting approval.
- `weekly` → weekly review with medians per platform and one next single-variable test.
- `metrics ...` → record the pasted numbers into scoreboard.csv; blanks stay blank.

Show the owner the resulting report. Never invent numbers.
